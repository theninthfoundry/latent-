# Neam Creative Studio — Skiper UI Showcase

A Next.js 14+ Creative Design Studio landing page featuring custom components from the [Skiper UI](https://skiper-ui.com) ecosystem.

## Featured Skiper UI Components

1. **`@skiper-ui/skiper8`** — *Words Preloader*
   - Located at: `src/components/skiper-ui/skiper8.tsx`
   - Multilingual animated text reveal cycling through international greetings.
   - Morphing SVG curved bottom wave exit transition inspired by Dennis Snellenberg.

2. **`@skiper-ui/skiper54`** — *clipPath Carousel (`Carousel_006`)*
   - Located at: `src/components/skiper-ui/skiper54.tsx`
   - Embla Carousel with Framer Motion `clipPath` depth transition (`inset(14% ...)` to `inset(0% ...)`).
   - Animated project title blur reveals, category chips, navigation arrows, and pagination.

3. **`@skiper-ui/skiper39`** — *Canvas Crowd Simulator*
   - Located at: `src/components/skiper-ui/skiper39.tsx`
   - Embedded directly in the footer section (`src/components/footer.tsx`).
   - HTML5 `<canvas>` simulation powered by GSAP and Open Peeps illustrations (by Pablo Stanley & Szenia Zadvorny).
   - Features randomized walking timelines, depth sorting, and responsive device pixel scaling.

## Quick Start

Install dependencies and start the development server:

```bash
# Using pnpm (recommended)
pnpm install
pnpm dev

# Or using npm
npm install
npm run dev

# Or using yarn
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
